DataMind AI

Conversational analytics platform, FlowZint AI Hackathon 2026

Lets people ask questions about their spreadsheets in plain English and get SQL results and charts back, without writing queries.

Python, Pandas, Streamlit, SQLite, Plotly, Groq API

Live demo
Case study

The problem

Business data sits in CSV and Excel files that only people who know SQL can query.

The solution

A chat interface that converts natural-language questions into SQL, runs them, and picks a chart automatically.

Architecture

Nine object-oriented modules covering NL-to-SQL, SQL querying, auto-charting, data cleaning and dashboarding. A Pandas layer reads CSV and Excel files, and the LLM is called over REST.

How it works

Multi-turn chat state carries earlier questions forward, so follow-ups can refer to previous results.

Deployment

Hosted on Streamlit Cloud.

ClauseLens

Rental agreement analyzer, WeMakeDevs First Commit 2026, scored 24/30

Reads a rental agreement PDF, finds the clauses that matter to a tenant, and explains them in simple language.

Python, Streamlit, AWS Textract, Amazon S3, Amazon Polly

Live demo
Case study

The problem

Rental agreements are long and dense, and key terms are easy to miss.

The solution

The app extracts the text, identifies clauses on deposits, lock-in periods, eviction and termination, and highlights them.

Architecture

Amazon Textract handles extraction, S3 handles storage, and a Streamlit front end shows highlights and simplified explanations.

Accessibility

Amazon Polly adds text-to-speech so explanations can be listened to.

Note on the demo

The live link points to a raw server address and port, so it may be offline at times.
